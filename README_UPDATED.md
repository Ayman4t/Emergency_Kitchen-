# بديل المطبخ — النسخة المعدلة

## ما تم تعديله
- إزالة زر «المصادر» من شريط العنوان العلوي.
- تغيير عنوان لوحة المراجع إلى «مراجع قاعدة البيانات».
- استبدال الاسم الإنجليزي الظاهر `Half-and-Half` باسم عربي أوضح: «خليط الحليب والكريمة الخفيفة».
- إبقاء الاسم الإنجليزي كوسم بحث فقط، حتى يستطيع المستخدم البحث عن المصطلح إذا صادفه في وصفة أجنبية.
- الاحتفاظ بالمراجع داخل بطاقات البدائل وداخل لوحة المراجعة.
- إنشاء ملف مستقل `ingredients.json` يحتوي على قاعدة البيانات كاملة.

## قاعدة البيانات
- 120 مكوّنًا.
- 280 خيار استبدال.
- كل بديل يحتوي على الاسم، النسبة، الاستخدام الأنسب، التأثير، درجة الثقة، المصدر، وملاحظات السلامة عند الحاجة.

## الملفات
- `index.html`: الموقع الكامل، ويعمل كما هو بدون الحاجة إلى تحميل JSON خارجي.
- `ingredients.json`: نسخة منظمة من قاعدة البيانات تصلح لاحقًا كملف بيانات منفصل أو كمصدر لـ API.
- `SOURCES.md`: المراجع وسياسة استخدام بيانات الاستبدال.

## ملاحظة حول Half-and-Half
المقصود هو منتج ألبان أمريكي شائع يتكون من خليط حليب وكريمة خفيفة، ويستخدم كثيرًا في القهوة والصوصات وبعض الوصفات. تم تعريب الاسم في الواجهة لتجنب ترك مصطلح إنجليزي غير واضح للمستخدم العربي.

## تشغيل الموقع
افتح `index.html` مباشرة في المتصفح. قاعدة البيانات مدمجة داخله، لذلك لا توجد مشكلة CORS عند تشغيل الملف محليًا.
